## Purpose of this document

This document defines how content for the Kids vertical should be created.

The goal is not just to show kids playing.

The goal is to make parents think:

> “This is actually useful for my child”

and then take action to book a trial.

Every piece of content must clearly communicate at least one:

* Athletic development
* Reduced screen time
* Physical growth (movement, stamina, coordination)

If content is only “kids playing”, it will fail.

---

## Core Content Strategy (Kids Page)

Right now your raw material is good:

* Kids behave naturally
* You have real gameplay
* Parents testimonials exist

But messaging is missing.

So the strategy is:

> Show fun → Explain benefit → Build trust → Push trial

---

## Content System Overview

We will use **5 repeatable content systems**.

Each one balances:

* Kid attraction (visual fun)
* Parent assurance (clear value)

---

## 1. “Fun Outside, Growth Inside” Montage

This is your primary reach format.

But unlike adult, here **fun alone is not enough**.

### Structure

Start with high-energy kids playing:

* Running
* Jumping
* Competing

Immediately add overlay text that translates fun into value.

### Hook Styles

* “Ungaloda kid full day mobile la dhan iruka?”
* “Energy iruku… aana use aagala?”
* “Ithu just game illa…”

### Middle Layer (Important)

While showing games, add meaning:

* “Improves coordination”
* “Builds stamina”
* “Team play learning”
* “Agility + balance”

### Ending

Show:

* Kids smiling
* Group energy

### CTA

* “Free trial session available”
* “Call pannitu book pannunga”

### Key Rule

Never leave visuals without explanation.

Parents must understand:

> Why this play matters

---

## 2. Parent Problem → Clear Solution

This is where conversion starts.

### Structure

Start with a strong parent pain:

“Kids ipo full time mobile la dhan irukaanga”

Then build tension:

“Outdoor activity almost illa”

Then solution:

“Games moolama movement build panrom”

### Flow

Problem → Concern → Insight → Tribe Fortis solution → CTA

### Messaging Angles

* Screen addiction
* Low physical activity
* Lack of sports exposure

### CTA

* “Oru session try pannunga”
* “Free trial ku call pannunga”

---

## 3. Coach Explains (Trust Builder)

This is critical. Without this, parents won’t take it seriously.

### Format

Coach speaking clearly.

But not long lectures.

### Structure

Hook:

“Why games are important for kids development…”

Then:

Explain simply:

* Movement
* Coordination
* Athletic base

Then connect:

“Adhanala dhan structured games use panrom”

### Style

* Calm but confident
* Simple language
* No jargon

### CTA

* “Trial session la neenga paathu decide pannunga”

---

## 4. Parent Testimonial (High Trust Content)

This is your strongest conversion asset if done right.

### Format

Parent speaking OR text-led.

### Structure

Start with:

“Enoda paiyan earlier active ah illa…”

Then:

“Now he is more active / energetic”

Then:

“Screen time koranjiduchu”

### Cutaways

* Kid playing
* Smiling
* Engaging

### CTA

* “Same problem na try pannunga”

### Important

Make it:

* Real
* Specific
* Not over-polished

---

## 5. First-Time Kid Experience

This builds relatability + curiosity.

### Structure

Show:

* Kid entering (slightly shy/confused)
* Slowly joining
* Playing
* Enjoying

### Hook

“First day unga kid ipdi dhan irupa…”

### Flow

Hesitation → Participation → Enjoyment → Comfort

### CTA

* “First session free. Try pannunga”

---

## Posting Guidelines

Unlike adults, kids content should not be too aggressive.

Balance is important.

* 4–5 strong reels per week is enough
* Focus on clarity, not quantity

---

## What to STOP doing

* Only kids playing without explanation
* Over-fun without structure
* Too random clips
* No clear messaging

If parent cannot understand in 3 seconds:

> What is this?

Content fails.

---

## CTA System

Rotate naturally:

* “Free trial session available”
* “Call pannitu book pannunga”
* “Unga kid ku try pannunga”
* “Experience pannitu decide pannunga”

---

## Tone Execution Rule (Very Important)

Every content should feel like:

**To kid:**

> “This looks fun, I want to go”

**To parent:**

> “This is useful, I should enroll”

If only one side works, content is incomplete.

---

## Final Clarity

Your biggest mistake till now:

> Showing activity without meaning

Your fix going forward:

> Show activity + explain outcome

If you do this consistently, parents will start understanding the value—and that’s when conversions start.
