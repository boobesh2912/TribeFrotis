## Purpose of this document

This calendar is designed to:

* Maintain consistent posting
* Maximize reach using proven formats
* Align content with shooting reality
* Drive trial sessions and inquiries

This is not a rigid plan.
This is a **structured system with flexibility**.

---

## Weekly Content Structure

You will post:

* **6 reels per week total**

  * Adults → 2
  * Kids → 2
  * Corporate → 2

No fillers. No random posts.

---

## Event Integration System (Important)

You already do weekly events (Saturday).

Use this smartly:

### Wednesday Content

→ Promote upcoming weekend event

Example:

* “This Saturday: Beach run / games / badminton”
* Build curiosity

### Saturday/Sunday Content

→ Capture and reuse

From ONE event, extract:

* 1 Adult reel
* 1 Corporate reel
* Optional Kids content (if relevant)

👉 This reduces shooting pressure.

### Corporate

## What NOT to do anymore

* No random posting
* No static posts just to “fill”
* No carousels unless extremely strong
* No posting without hook

If content is weak → skip, don’t post.

---

## Weekly Execution Checklist

Before posting, check:

* Does this have a strong hook?
* Is the message clear in first 3 seconds?
* Is there a clear CTA?
* Does it match the correct audience?

If not → fix before posting.
